# Aula 4 · Do pedido ao cartão

Comece pelo **captador da Orbita** para acompanhar um pedido desde o formulário da campanha até o cartão no Trello. Os outros exemplos podem ser testados separadamente.

Na aula de 23/11/2026, a turma fez a nota, a faixa e o cartão no Trello. O formulário, o resumo diário, o HTTP (feriados, Basic e Bearer), o Loop e o Google Sheets são vistos no começo da [aula 5](../AULA%2005/README.md).

| O que você quer fazer? | Por onde começar |
|---|---|
| Entender o Code, o Switch, o Filter, o Loop e o HTTP Request em exemplos curtos | [Conceitos antes do captador](CONCEITOS/README.md) |
| Preparar o quadro do Trello ou experimentar a mesma organização no Notion | [Modelos de CRM](Modelos%20de%20CRM/README.md) |
| Dar uma nota ao pedido, escolher a etiqueta e encontrar o cartão pela tabela | [Captador da Orbita no Trello](Captador%20da%20Orbita%20no%20Trello/README.md) |
| Receber um pedido pelo formulário do próprio n8n | [Formulário de pedido](Formulario%20de%20pedido/README.md) |
| Contar os pedidos que chegaram no dia anterior | [Resumo diário de leads](Resumo%20diario%20de%20leads/README.md) |
| Fazer a primeira consulta HTTP, sem credencial | [Consultar feriados](Consultar%20feriados/README.md) |
| Descobrir onde informar o usuário e a senha de uma API | [HTTP com Basic Auth](HTTP%20com%20Basic%20Auth/README.md) |
| Descobrir onde informar o token de uma API | [HTTP com Bearer](HTTP%20com%20Bearer/README.md) |
| Acrescentar um pedido à aba `Pedidos` da planilha | [Gravar no Google Sheets](Gravar%20no%20Google%20Sheets/README.md) |
| Receber no n8n a próxima linha acrescentada nessa aba | [Receber nova linha do Google Sheets](Receber%20nova%20linha%20do%20Google%20Sheets/README.md) |

Para cada exemplo, baixe o JSON pelo botão **Download raw file** do GitHub. Abra um workflow vazio no n8n e, no menu **⋯**, escolha **Import from File**. A nota **Leia primeiro** no próprio fluxo e o README da pasta mostram o que preencher e como reconhecer o resultado. Use dados fictícios nos testes.
