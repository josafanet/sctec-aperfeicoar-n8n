# Aula 3 · Expressões, caminhos e avisos

Seis exemplos para treinar o que vimos na aula 3. Cada pasta tem o fluxo e um README com o que fazer. A Orbita como ficou no fim da aula está em [PROJETO/Orbita Labs v3](../../PROJETO/Orbita%20Labs%20v3/README.md).

| O que você quer fazer | Por onde começar |
|---|---|
| Rodar o fluxo sem abrir a página a cada teste | [01 Testar sem preencher a página](01%20Testar%20sem%20preencher%20a%20pagina/README.md) |
| Escolher entre WhatsApp, e-mail ou nenhum contato | [02 Escolher o contato com IF](02%20Escolher%20o%20contato%20com%20IF/README.md) |
| Ver a ordem dos caminhos, o Wait e o Merge | [03 Esperar dois caminhos](03%20Esperar%20dois%20caminhos/README.md) |
| Ler o que já está gravado na tabela | [04 Buscar os leads da tabela](04%20Buscar%20os%20leads%20da%20tabela/README.md) |
| Montar uma mensagem e enviar no Slack | [05 Montar um resumo e avisar no Slack](05%20Montar%20um%20resumo%20e%20avisar%20no%20Slack/README.md) |
| Dar nota ao pedido e separar por faixa | [06 Dar nota e separar por faixa](06%20Dar%20nota%20e%20separar%20por%20faixa/README.md) |

Para importar, abra o JSON da pasta no GitHub e clique em **Download raw file**. No n8n, crie um workflow vazio e escolha **Import from File** no menu de três pontinhos. Os fluxos chegam desativados. Use só dados inventados nos testes.

Os exemplos 04, 05 e a Orbita v3 pedem coisas da sua conta. O 04 usa a sua tabela `leads`. O 05 e a Orbita v3 usam a sua credencial do Slack.
